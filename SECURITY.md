## "Do No Harm" & Vulnerability Reporting

DiskRescue handles raw physical block devices and low-level filesystem structures. We take safety, non-destructive defaults and write-blocking compliance seriously.

If you discover a security vulnerability or a scenario where write-blocking fails or unverified data overwrite could occur:
1. Please do not open a public issue.
2. Email the maintainer at **kaio@example.com** (or contact directly via GitHub private vulnerability reporting).
3. Provide steps to reproduce, device type, and test logs.
